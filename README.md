# Mây AI Travel Planner

Giao diện MVP cho ứng dụng lập lịch trình du lịch bằng AI, xây dựng bằng React và Vite.

## Chạy dự án

```bash
npm install
npm run dev
```

## Tính năng demo

- Form tạo chuyến đi theo điểm đến, thời gian, ngân sách và sở thích.
- Lịch trình AI mẫu theo từng ngày.
- Phân bổ ngân sách trực quan.
- Trợ lý du lịch dạng chat.
- Lưu và xem danh sách chuyến đi.
- Giao diện responsive cho desktop và mobile.

Hiện tại ứng dụng dùng dữ liệu demo ở frontend. Bước tiếp theo là kết nối Supabase và Gemini API qua Vercel Functions.
